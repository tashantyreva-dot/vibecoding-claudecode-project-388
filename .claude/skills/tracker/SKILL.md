# tracker

> ЗАГОТОВКА. Логику нужно дописать при реализации.

## Что делает

1. Читает `products.yaml` — параметры поиска (марка/модель/бюджет) и список источников (URL).
2. Для каждого источника вызывает скилл `extract-price` — получает список
   `{ price, year, mileage, url }`.
3. Загружает последний прошлый прогон из `runs/YYYY-MM-DD.json` (самый свежий по дате).
4. Сравнивает списки по `url`: находит новые и подешевевшие объявления
   по правилам значимости из `KNOWLEDGE.md`.
5. Шлёт уведомление в Telegram по значимым изменениям.
6. Сохраняет текущий прогон в `runs/<сегодня>.json`.

## Входные данные

- `products.yaml`
- `runs/*.json` — история прогонов
- `KNOWLEDGE.md` — правила «что считать поводом написать»

## Открытые вопросы

- Формат/секреты доступа к Telegram (bot token, chat id).
- Где хранить историю прогонов (репозиторий tracker-data).
