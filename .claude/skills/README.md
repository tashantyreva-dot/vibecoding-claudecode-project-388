# Skills

Заготовки для будущих скиллов «Трекера цен».

Каждый скилл живёт в своей подпапке `<имя-скилла>/` и обязательно содержит файл
`SKILL.md` с YAML-фронтматтером (`name`, `description`) и инструкциями. При необходимости
рядом можно класть вспомогательные файлы: `scripts/`, `references/`, шаблоны и т.п.

## Планируемые скиллы

- `tracker/` — обходит источники из `products.yaml`, вызывает `extract-price` для каждого,
  сравнивает результат с прошлым прогоном и шлёт уведомление в Telegram по правилам из
  `KNOWLEDGE.md`. Запускается по cron через Claude Code headless.
- `extract-price/` — открывает страницу источника, собирает все подходящие по цене
  объявления и возвращает список `{ price, year, mileage, url }`.

> Файлы `SKILL.md` в подпапках — это шаблоны-заготовки. Содержание нужно дописать при
> реализации.
