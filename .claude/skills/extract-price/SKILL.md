# extract-price

Извлекает объявления о продаже **MINI Countryman** (б/у) со страницы источника,
фильтрует по цене `< 1 200 000 ₽` и возвращает JSON-массив.

Реализация — Node.js + Playwright (headless-браузер), скрипт [`extract.js`](./extract.js)
(лежит рядом с этим файлом, а не в общей папке `scripts/`, — это вспомогательный
скрипт именно для этого скилла).

## Как запускать

```bash
node .claude/skills/extract-price/extract.js <URL>
```

Скрипт печатает в **stdout** JSON-массив объявлений:

```json
[
  { "price": 1100000, "year": 2012, "mileage": 142632, "url": "https://www.rolf.ru/cars/used/mini/countryman/22381355/" }
]
```

- `price` — число, рубли, без пробелов и `₽`;
- `year` — год выпуска (может быть `null`, если не удалось распарсить);
- `mileage` — пробег в км, число без `км` (может быть `null`);
- `url` — абсолютная ссылка на объявление.

Если подходящих объявлений нет — печатается `[]`. Только модель **Countryman**
(на сайтах с общим разделом «MINI» лишние модели отфильтровываются) и только
цена строго меньше `1 200 000 ₽`.

**Непустой результат — это не аномалия, а главная находка трекера.** Ниже описана
вёрстка и особенности источников (структурные, стабильные факты), а не то, что
на них сейчас продаётся, — цены и наличие меняются постоянно, и SKILL.md не место
для снимка рынка на дату проверки.

## Коды выхода

tracker должен ориентироваться на код выхода, а не только на stdout — чтобы
**не принять ошибку загрузки за «ничего не нашлось»**:

| код | значение                                                                 |
|-----|--------------------------------------------------------------------------|
| 0   | успех (в т.ч. пустой `[]`, когда подходящих объявлений действительно нет) |
| 1   | ошибка вызова (не передан/битый URL)                                     |
| 2   | страница не загрузилась (сеть, таймаут, ошибка навигации)                |
| 3   | источник заблокировал доступ (антибот / капча / HTTP 403 / нет карточек) |

Тексты ошибок (коды 1–3) идут в **stderr**.

## Как это работает

1. Запуск headless-браузера. Сначала пробуется системный Chrome
   (`channel: 'chrome'`), при его отсутствии — встроенный Chromium Playwright.
2. Контекст маскируется под обычный браузер (реальный User-Agent, `ru-RU`,
   скрытие `navigator.webdriver`) — иначе часть сайтов сразу отдаёт `403`.
3. Ожидание карточек через `waitForSelector` (а не просто `networkidle`) —
   для сайтов с JS-рендером списка.
4. Проверка на заглушку/капчу до чтения данных; при блокировке — выход с кодом 3.
5. Для каждого источника — свой парсер карточек (селекторы в `SITES`),
   фильтрация по модели и цене, сборка абсолютных URL.

## Селекторы и особенности источников

| источник           | статус | примечание |
|--------------------|:------:|------------|
| **rolf.ru**        | ✅     | Общий раздел MINI, фильтр по `/countryman/` в URL. Карточка `article.car-card-new`. |
| **avtodom.ru**     | ✅     | Список рендерится через JS — ждём селектор `.card`. Уже отфильтрован по Countryman. |
| **major-expert.ru**| ✅     | Общий раздел MINI, фильтр по `/countryman/` в URL. Карточка `a.car-card`. |
| **auto.ru**        | ⚠️     | Работает, но нестабильно из-за антибота (см. ниже). |

`статус` здесь — про надёжность извлечения (вёрстка/антибот), а не про то, что сейчас
найдено: наличие и цены объявлений на каждом источнике меняются от прогона к прогону.

### auto.ru — про антибот

- «Заглушка для вашего региона» / cookie-consent обходится: скрипт кликает
  кнопку согласия («Я согласен» / «Принять» / «Продолжить»), если она есть.
- Основной риск — **капча «Вы не робот?»** (Yandex SmartCaptcha). Она появляется
  непредсказуемо: из headless-контекста с маскировкой обычно проходит стабильно,
  но интерактивный браузер может ловить капчу на том же URL.
- Капчу мы **не обходим**. Если источник показал капчу/блок — скрипт не
  притворяется, что «ничего не нашлось», а завершается с кодом `3` и сообщением
  в stderr, чтобы tracker пропустил этот источник в текущем прогоне и попробовал
  позже.
- Классы вёрстки у auto.ru хешированные и меняются — привязка идёт к стабильному
  якорю ссылки `a[href*="/sale/mini/countryman/"]`, цена берётся из текста карточки
  (первое «N ₽» после пробега, чтобы не поймать «… ₽ со скидками» и суммы
  кредита/трейд-ина).

## Известные ограничения

- Читается **только первая страница** выдачи (пагинация не обходится). Для rolf /
  avtodom / major-expert этого достаточно (весь список на одной странице); у
  auto.ru на первой странице ~37 карточек — для трекера «новых и подешевевших»
  этого хватает, при необходимости пагинацию можно добавить.
- Парсинг завязан на текущую вёрстку сайтов. При смене вёрстки карточки перестанут
  находиться — скрипт вернёт код `3` («карточки не найдены»), а не пустой список,
  так что молчаливой потери данных не будет.
