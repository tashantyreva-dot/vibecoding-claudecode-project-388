# extract-price

> ЗАГОТОВКА. Логику нужно дописать при реализации.

## Что делает

1. Получает на вход URL источника и порог цены (из `products.yaml`).
2. Загружает страницу и собирает карточки объявлений.
3. Отфильтровывает по цене (и, при необходимости, по модели/году).
4. Возвращает список объектов `{ price, year, mileage, url }`.

## Технический риск (из README tracker-data)

Некоторые сайты (например, `avtodom.ru/cars/used/mini/countryman/`) подгружают
список объявлений через JS — в «сыром» HTML карточек нет. Для них простого
HTTP-запроса + парсинга недостаточно, понадобится рендеринг браузера.

Перед реализацией проверить, как отдаётся контент на:

- rolf.ru/used
- avtodom.ru
- major-expert.ru
- auto.ru

## Формат ответа

```json
[
  { "price": 1150000, "year": 2019, "mileage": 62000, "url": "https://…" }
]
```
